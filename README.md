# Platinum Cutz website

Static site for platinumcutz.studio, hosted free on GitHub Pages.

- `index.html`: all page content. Prices, hours and copy are plain text; search for the old value and replace it.
- `styles.css`: colors and layout. The accent color is `--pc-accent` at the top (red #C8372D; alternates blue #2F6BA8, gold #B8861F).
- Online booking: when a booking link exists, uncomment the "Book online" button in the `#book` section of `index.html` and paste the link.

Push to `main` and the site updates in a minute or two.
